# Privacy policy — XBBridge

_Last updated: 2026-10-27_

## 一句话

XBBridge 不收集、不上传、不分析任何数据。它只在你自己的电脑上，通过 `127.0.0.1` 的本地
WebSocket 和你自己启动的 `xb` 命令行工具通信。

## 它访问什么，为什么

| 访问 | 时机 | 去向 |
|---|---|---|
| 标签页标题 / URL / 状态 | 仅在你（或你运行的 `xb` 命令）请求时读取 | 只回给你本机的 `xb` 进程 |
| 页面内容（文本、HTML、截图） | 仅在你对某个标签执行 `text` / `snapshot` / `screenshot` 等命令时 | 同上，写到你的磁盘 |
| 剪贴板、Cookie、密码、历史、书签 | **从不访问** | — |
| 任何网络请求 | 不发起 | 唯一的网络连接是到 `ws://127.0.0.1:8787` 的本机回环连接 |

## 数据存储

扩展只在 `chrome.storage.local` / `chrome.storage.session` 中保存：

- 一个随机生成的实例 ID（用于区分同一台机器上的多个浏览器）
- 你给它起的可读名字（label）
- 当前受控标签的标记表、租约令牌
- 最近一次未捕获异常（便于排查）

这些内容全部留在本机浏览器配置目录内，不上传，不同步，随卸载一起删除。

## 第三方

无。没有分析 SDK、没有崩溃上报、没有广告、没有远程配置、没有远程代码。
扩展包里就是全部代码，可自行解压审阅。
